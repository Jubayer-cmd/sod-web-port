# Put your own copy of the game here

This folder is intentionally empty in the repository. The game is copyrighted by Gameloft and
is **not** distributed with this project.

Copy the original J2ME file you own into this folder as:

```
game/SoulOfDarkness.jar
```

The build verifies it is the exact release this port targets
(`SoulOfDarkness_HTC_P3450_EN_IGPL_EU_101_S8000.jar`, v1.0.1, 240×320 touch build):

```
SHA-256  3da9ea7fe8dfaa2c090e8b3714eaed15127f51dc8b67ed9ef9fed51172e4bea4
```

Everything in this folder except this README is ignored by git.
